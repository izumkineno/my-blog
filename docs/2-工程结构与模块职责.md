## 目录职责

| 路径 | 职责 |
| --- | --- |
| `src/config.ts` | 站点标题、语言、主题色、Banner、导航、个人资料、许可证和代码块主题 |
| `src/content/config.ts` | Astro Content Collections 的 `posts` 与 `spec` schema |
| `src/content/posts/` | 博客文章及文章所属的图片资源 |
| `src/content/spec/` | 非文章页面内容，目前由 About 页面读取 |
| `src/pages/` | Astro 文件路由和 RSS、robots.txt 等 API 路由 |
| `src/layouts/` | 页面级布局，负责页面外壳和主要网格结构 |
| `src/components/` | Astro 与 Svelte UI 组件 |
| `src/utils/` | 文章排序、URL、日期和设置等跨组件逻辑 |
| `src/plugins/` | Markdown、rehype 和 Expressive Code 扩展 |
| `src/i18n/` | 翻译键、翻译函数和各语言文本 |
| `src/styles/` | Tailwind、Stylus 和全局 Markdown 样式 |
| `src/assets/` | 由 Astro 处理的站点图片资源 |
| `src/types/` | TypeScript 配置类型和文章数据类型 |
| `public/` | 原样复制到站点根目录的静态文件，例如 favicon |
| `cms/` | Sveltia CMS 管理页面和内容集合配置 |
| `scripts/cms-server.mjs` | 仅监听回环地址的 CMS 静态资源服务 |
| `scripts/new-post.js` | 创建 page bundle 格式的草稿文章 |
| `docs/` | 面向开发者和使用者的 Markdown 文档 |

## 页面路由

| 文件 | 生成内容 |
| --- | --- |
| `src/pages/[...page].astro` | 首页文章列表及分页页面 |
| `src/pages/posts/[...slug].astro` | 单篇文章页面 |
| `src/pages/archive.astro` | 文章归档、标签和分类筛选 |
| `src/pages/about.astro` | 从 `src/content/spec/about.md` 读取的 About 页面 |
| `src/pages/rss.xml.ts` | RSS feed |
| `src/pages/robots.txt.ts` | robots.txt |

## 主要数据流

```text
src/content/posts/**/index.md
        ↓
src/content/config.ts
        ↓
getSortedPosts / getSortedPostsList
        ↓
src/pages + src/components + src/layouts
        ↓
astro build
        ↓
dist/ + Pagefind search index
```

生产环境中，`src/utils/content-utils.ts` 会排除 `draft: true` 的文章；开发环境会保留草稿，便于本地预览。文章按 `published` 日期倒序排列，并由同一处逻辑提供首页、文章页和归档页所需数据。

## 导入路径别名

`tsconfig.json` 定义了以下别名：

| 别名 | 目标 |
| --- | --- |
| `@components/*` | `src/components/*` |
| `@assets/*` | `src/assets/*` |
| `@constants/*` | `src/constants/*` |
| `@utils/*` | `src/utils/*` |
| `@i18n/*` | `src/i18n/*` |
| `@layouts/*` | `src/layouts/*` |
| `@/*` | `src/*` |

新增跨模块导入时优先复用这些别名。构建生成的 `.astro/`、`dist/` 和依赖目录不属于源码修改范围。
