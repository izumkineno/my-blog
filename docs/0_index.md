## 工程概览

- 技术栈：Astro 5、Svelte 5、Sveltia CMS、Tailwind CSS 3、TypeScript 和 Biome。
- 内容入口：`src/content/posts/` 中的 Markdown 文章。
- 站点配置：`src/config.ts`。
- 路由入口：`src/pages/`。
- 生产构建：`pnpm build` 先运行 `astro build`，再使用 Pagefind 为 `dist/` 生成搜索索引。
- 包管理器：仓库声明的版本为 `pnpm@9.14.4`，依赖通过 `pnpm-lock.yaml` 锁定。

## 文档维护约定

- 新增开发文档使用数字前缀，并在本文件中登记链接。
- 命令、路径和配置项以当前 `package.json`、源码和 CI 配置为准；发现冲突时先修正文档，再修改示例。
- 文档中的路径均以仓库根目录为基准；文档之间的链接使用相对路径。
- 修改脚本、目录或发布流程后，至少重新检查受影响文档中的命令和路径。
